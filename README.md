# SaysData

SaysData lets you be confident in your agent's data analysis by providing access to trustworthy
data, running automated checks on its queries and making it easy for you to verify the results.
Includes data from Statistics Canada, Eurostat, the OECD and other national statistics agencies
and international organizations.

This plugin adds a skill that teaches your agent to use SaysData well: find the right dataset,
compute every figure with a query, read the warnings that come with each result, and report each
number with its source, its citation and a link to check it.

## Setup

The skill works through the SaysData connector, which installing the plugin doesn't connect. After
installing, add the SaysData connector from the plugin's page, connect it, and sign in with your
SaysData account. Without the connector, the skill has no data to query.
